# Healthcare Project — Team Handoff Pack

Read these files in this order:

1. `01_PROJECT_OVERVIEW.md` — project purpose, objectives and architecture.
2. `02_REPOSITORY_FILE_GUIDE.md` — what the important folders/files do.
3. `03_DATASET_GUIDE.md` — datasets, generated artifacts and data handling.
4. `04_BACKEND_FRONTEND_INTEGRATION.md` — what the backend/frontend should build.
5. `05_STATUS_REMAINING_FUTURE_SCOPE.md` — completed work, remaining work and future scope.
6. `06_INTEGRATION_PLAN.md` — step-by-step plan for the remaining work, checked against the code.

Also read `ML/ML_handoff.md` from the repository for the ML-specific handoff.

Important: `.env` and local `config.py` are intentionally excluded from GitHub because they contain local configuration/secrets.
